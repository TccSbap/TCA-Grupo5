# ODS 6 - Site de Denúncias sobre Saneamento Básico

npm install i
para instalar as dependências.

# - 1 Para Usuários Normais
-  Cadastro e login de usuários
-  Criação de denúncias sobre problemas de saneamento
-  Visualização de denúncias públicas
-  Acompanhamento do status das próprias denúncias
-  Dashboard pessoal com estatísticas
-  Visualização de ONGs parceiras

# - 2 Para ONGs (Administradores)
-  Cadastro como organização
-  Painel administrativo completo
-  Resposta às denúncias dos usuários
-  Atualização de status das denúncias
-  Estatísticas de desempenho
-  Gerenciamento de casos

# - 3 Funcionalidades Gerais
-  Sistema de autenticação seguro
-  Interface responsiva e moderna
-  Páginas informativas (Sobre, Contato)
-  Sistema de filtros para denúncias
-  Dados de demonstração pré-carregados
